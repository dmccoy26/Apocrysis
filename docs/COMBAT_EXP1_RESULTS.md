## The two run-7 cases

- **Case A** (exp 1 t5 — Starter vs Regular, L1, fresh, no armor): card shows **LOW / "overkill" / Fight ~100%**. Actual: p90 loss **66 HP (66% of max)**, worst **98 (98%)**. The card says trivial; the p90 says half-dead.
- **Case B** (exp 3 t9 — Chipped Sword vs Heavy, L3, worn, no armor): card shows **EXTREME / "poorly suited" / Fight ~4%**. Actual win rate 4% — the card is honest here; this is a model / ramp problem, not a communication one.

## What this says for the attention spec

`threat_tier` and `weapon_verdict` are pure functions of `P(win)`. Every row above where a LOW/MODERATE tier sits next to a p90 loss over ~40% max-HP is a cell where the attention level (which the spec derives from the forecast) would be set too low. The fix is in `combat_forecast`, not the attention renderer — `threat_tier = f(P(win), expected_HP_loss_fraction, worst_case_HP)`.
